# AIPin — 魔兽世界：Forever 地图标记插件

让 AI 助手把 NPC 和地点标在你的地图上、帮你记待办，并读取你的角色信息给出建议。

## 安装

1. **先完全退出**游戏。
2. 解压 `AIPin.zip`，把 `AIPin` 文件夹（里面直接有 `AIPin.toc`）放进 Forever 插件目录：
   - Windows：`C:\Program Files (x86)\World of Warcraft\_forever_\Interface\AddOns\`
   - Mac：`/Applications/World of Warcraft/_forever_/Interface/AddOns/`

   **不要**多套一层 `AIPin\AIPin\`。游戏装在别处的话，在战网客户端 Forever 的齿轮菜单里打开游戏文件夹。
3. 启动游戏，在角色选择界面点「插件」，勾选 **AIPin**（如果显示过期，也勾选「加载过期插件」）。

也可以让 AI 助手帮你装：把 https://wow.duxi.ao/INSTALL.md 发给 Claude Code、Codex 等助手。

### 更新

退出游戏 → 下载新的 `AIPin.zip` → 删掉旧的 `AIPin` 文件夹，换成新的。标记、待办和角色信息都保存在 `WTF` 文件夹里，不会丢失。
如果助手用 `Inbox.lua` 推送过标记或待办，替换前先备份旧的 `Inbox.lua`，换完再放回去。

## 地图标记

聊天框粘贴助手发来的指令，例如：

```
/aipin 丹莫罗 44.1 57.1 巡山人格雷琴
/aipin Dun Morogh 44.1 57.1 Mountaineer Gretchen
/aipin 44.1 57.1 巡山人格雷琴
```

- 坐标是地图百分比（0–100），和 Wowhead 一样。区域名中英文都可以；省略区域或认不出区域名时，用你当前所在的地图。
- 标记以 AIPin 图标显示在世界地图上，鼠标悬停显示名字、区域和坐标。按 **M** 打开地图查看。
- 最新的标记会设置游戏自带的路点（导航箭头），箭头上显示标记名字。某张地图不允许设路点时，标记仍会保存并显示在世界地图上。
- 最多保留最近 20 个标记；在同一位置再标一次只会更新名字。
- `/aipin list` 列出标记，`/aipin clear` 清除全部。

## 待办与地理提醒

```
/aipin todo 买背包                        普通待办
/aipin todo 学法杖 @ 暴风城                进入暴风城时提醒
/aipin todo 学法杖 @ 暴风城 63.9 69.1      走到那附近时提醒
```

提醒会显示在聊天框和屏幕中央，并播放提示音。离开后再回来会再次提醒；标为完成就不再提醒。

其它命令：`/aipin todos` 列出（带编号），`/aipin done N` / `/aipin undone N` 标为完成 / 未完成，`/aipin deltodo N` 删除，`/aipin cleartodos` 清除已完成的待办。

## 小地图按钮与面板

- **左键：打开面板**，分「待办」和「标记」两个标签页。
  - 待办页：输入新待办（同样可以写 `@ 区域`），「提醒在此处」用你当前位置添加地理提醒；勾选完成，✕ 删除，「清除已完成」批量清理。
  - 标记页：逐个删除或全部清除。
  - 底部显示上次同步时间和收件箱版本，还有「同步」按钮。
- **右键：同步。**
- 按钮右下角的数字是未完成的待办数量；拖动按钮可以沿小地图边缘移动；`/aipin minimap` 显示 / 隐藏按钮。

## 同步

右键小地图按钮，或输入 `/aipin sync`：保存角色信息、导入助手推送的标记和待办，然后重载界面。战斗中不能同步。

## 角色信息

AIPin 会记录你的等级、经验、金币、位置和坐标、天赋、专业、任务进度、装备、背包空位和炉石位置，助手读取后就不用你一项项告诉它。

- 游戏只在同步、`/reload`、下线或切换角色时写入文件。问助手之前同步一下，数据就是最新的。
- 文件位置：`_forever_/WTF/Account/<账号>/SavedVariables/AIPin.lua`。
- 已学的专业图样按角色单独保存（`WTF/Account/<账号>/<服务器>/<角色>/SavedVariables/AIPin.lua`），助手可以据此推荐做什么装备。游戏只在专业窗口打开时提供图样，所以每个专业窗口至少要打开一次。
- `/aipin me` 在聊天框显示简要信息（等级、位置、任务数）。
- 数据只保存在你自己的电脑上，插件不会联网。

## 给 AI 助手

把同一目录里的 `AGENTS.md` 发给你的 AI 助手（网上也有：https://wow.duxi.ao/AGENTS.md）。里面写了怎么生成 `/aipin` 指令、怎么编辑 `Inbox.lua` 推送标记和待办，以及怎么根据你的角色信息给建议。

`Inbox.lua` 是收件箱：助手直接改这个文件，你右键小地图按钮同步，新的标记和待办就会导入，导入过的不会重复。第一次安装后要完全重启游戏一次，之后同步就够了。

## 其它

`/aipin help` 显示全部命令，`/ap` 是 `/aipin` 的简写。
