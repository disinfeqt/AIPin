AIPin

《魔兽世界：Forever》插件：让 AI 助手把 NPC 和地点标在你的地图上，并读取你的角色信息。 A World of Warcraft: Forever addon that lets your AI assistant pin NPCs and places on your map and read your character info.

功能Features

地图标记Map pins

NPC 和地点以金色图钉标在世界地图上，悬停显示名字和坐标。点图钉或面板里的一行，导航点就设到那里。NPCs and places show as gold pins on the world map; hover for name and coordinates. Click a pin, or its row in the panel, to make it the waypoint.

待办清单 & 地理提醒Todos & geo-reminders

给待办加上区域，比如 @ 暴风城，到了就提醒。Give a todo a zone, such as @ Stormwind, and get reminded when you arrive.

助手推送Assistant push

能改文件的 AI 助手把标记和待办写进 Inbox.lua，同步后导入。Agents that can edit files write pins and todos into Inbox.lua; they're imported on sync.

角色信息Character snapshot

等级、金币、位置、天赋、专业、任务、装备和已学图样，供助手读取。Level, money, location, talents, professions, quests, gear and learned recipes, for your assistant to read.

小地图按钮Minimap button

左键打开待办和标记面板，右键同步。Left-click for todos and pins, right-click to sync.

安装Install

  1. 下载 AIPin.zip，然后完全退出游戏。Download AIPin.zip, then quit the game completely.
  2. 解压，把 AIPin 文件夹放进 _forever_/Interface/AddOns/。Unzip it and put the AIPin folder in _forever_/Interface/AddOns/.
  3. 启动游戏，在角色选择界面点「插件」，勾选 AIPin。Start the game, click AddOns on the character select screen and enable AIPin.

更新Updating

退出游戏，用新的 AIPin 文件夹替换旧的。数据存在 WTF 文件夹里，不会丢失。Quit the game and replace the old AIPin folder with the new one. Your data lives in WTF and is kept.

用法Usage

把助手给的指令粘贴到聊天框。坐标和 Wowhead 一样；省略区域则用当前地图。Paste your assistant's command into chat. Coordinates are the same as Wowhead; leave out the zone to use your current map. In-game text is in Chinese.

示例Examples
/aipin 丹莫罗 44.1 57.1 巡山人格雷琴
/aipin todo 学法杖 @ 暴风城/aipin Dun Morogh 44.1 57.1 Mountaineer Gretchen
/aipin todo Learn staves @ Stormwind
/aipin <区域zone> <x> <y> <名称title>
添加标记Add a pin
/aipin list / clear
列出 / 清除标记List / remove pins
/aipin todo <内容text> [@ <区域zone> [x y]]
添加待办，带区域则到了提醒Add a todo; with a zone, remind on arrival
/aipin todos
列出待办List todos
/aipin done N / undone N / deltodo N
完成 / 取消完成 / 删除第 N 条Mark done / not done / delete todo N
/aipin cleartodos
清除已完成的待办Remove finished todos
/aipin me
显示角色信息Show character info
/aipin sync
保存角色信息，导入助手推送（重载界面）Save character info and import pushes (reloads the UI)
/aipin minimap
显示 / 隐藏小地图按钮Toggle the minimap button
/aipin help
全部命令All commands
/ap
/aipin 的简写Short for /aipin
小地图按钮Minimap button
左键面板，右键同步，可拖动Left-click for the panel, right-click to sync, drag to move
